# MSKM - Multiple SSH Key Manager CLI

This project, is a simple CLI to manage multiple SSH Keys easily!

## Installation

You can install the package via npm:

```bash
npm i @txsoura/mskm
```

## Documentation

See the [WIKI](https://github.com/txsoura/mskm/wiki) for documentation.
